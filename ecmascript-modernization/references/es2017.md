# ES2017 Modernization

Use `"target": "ES2017"` and `"lib": ["ES2017", ...]` or newer. For async-heavy Node and browser apps, ES2017 is the first truly practical baseline because it includes native `async`/`await` and common object helpers.

## async And await

Use `async`/`await` for promise flows with branching, loops, or error handling.

Use this:

```ts
async function loadUser(id: string) {
  try {
    const response = await fetch(`/api/users/${id}`);
    return await response.json();
  } catch (error) {
    logger.error(error);
    return null;
  }
}
```

Not that:

```ts
function loadUser(id: string) {
  return fetch(`/api/users/${id}`)
    .then((response) => response.json())
    .catch((error) => {
      logger.error(error);
      return null;
    });
}
```

Replaces:

- deeply nested `.then()` chains
- promise chains with multiple branches
- manual `new Promise()` wrappers around already-promise-returning code

Use with care:

- Keep `.then()` for simple fluent transformations where it is clearer.
- Do not `await` independent promises one after another when `Promise.all()` would preserve concurrency.

## Object.values And Object.entries

Use `Object.values()` and `Object.entries()` to iterate object values or key-value pairs.

Use this:

```ts
const total = Object.values(counts).reduce((sum, count) => sum + count, 0);

for (const [id, user] of Object.entries(usersById)) {
  syncUser(id, user);
}
```

Not that:

```ts
const total = Object.keys(counts).reduce((sum, key) => sum + counts[key], 0);

for (const id of Object.keys(usersById)) {
  syncUser(id, usersById[id]);
}
```

Replaces:

- `Object.keys(obj).map((key) => obj[key])`
- `for...in` loops with `hasOwnProperty()` guards for plain own enumerable data
- local `entries()` helpers

Use with care:

- These only include own enumerable string-keyed properties.
- Use `Reflect.ownKeys()` when symbol keys or non-enumerable properties matter.

## Object.getOwnPropertyDescriptors

Use descriptors when copying property definitions, not just values.

Use this:

```ts
const clone = Object.defineProperties(
  {},
  Object.getOwnPropertyDescriptors(source),
);
```

Not that:

```ts
const clone = Object.assign({}, source);
```

Replaces:

- descriptor-losing clones for objects with getters, setters, or non-default property attributes

Use with care:

- Use object spread or `Object.assign()` for ordinary data objects.
- Descriptor-preserving copies are a specialized tool for libraries, decorators, and meta-programming.

## String Padding

Use `padStart()` and `padEnd()` for fixed-width text.

Use this:

```ts
const invoiceNumber = String(sequence).padStart(6, "0");
```

Not that:

```ts
const invoiceNumber = `000000${sequence}`.slice(-6);
```

Replaces:

- manual prefix/suffix concatenation
- custom left-pad/right-pad helpers for simple strings

Use with care:

- Padding is based on string length, not display width. Avoid it for terminal table alignment with wide Unicode text unless a display-width library is already used.

## Trailing Commas In Function Parameters

Use trailing commas in multiline parameter and argument lists when the formatter/project style allows it.

Use this:

```ts
createUser(
  name,
  email,
  role,
);
```

Not that:

```ts
createUser(
  name,
  email,
  role
);
```

Replaces:

- noisy diffs when adding a final argument or parameter

Use with care:

- Let the project formatter decide. Do not churn files only to add trailing commas.
