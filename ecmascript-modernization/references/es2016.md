# ES2016 Modernization

Use `"target": "ES2016"` and `"lib": ["ES2016", ...]` or newer. For modern projects, prefer the newest edition your runtime supports rather than stopping at ES2016.

## Array.prototype.includes

Use `includes()` when checking whether an array contains a value.

Use this:

```ts
const isAllowed = allowedRoles.includes(user.role);
```

Not that:

```ts
const isAllowed = allowedRoles.indexOf(user.role) !== -1;
```

Replaces:

- `indexOf(value) !== -1`
- `indexOf(value) >= 0`
- small `contains(array, value)` helpers

Use with care:

- `includes()` uses SameValueZero equality, so it can find `NaN`. That is usually an improvement over `indexOf()`.
- Keep `find()` when the check depends on a predicate rather than direct value equality.

## Exponentiation Operator

Use `**` for exponentiation.

Use this:

```ts
const area = Math.PI * radius ** 2;
```

Not that:

```ts
const area = Math.PI * Math.pow(radius, 2);
```

Replaces:

- `Math.pow(base, exponent)` in ordinary arithmetic expressions

Use with care:

- Keep `Math.pow()` when passing the operation as a function value or when it reads better in a higher-order expression.
- Parenthesize unary expressions: `(-value) ** 2`.
