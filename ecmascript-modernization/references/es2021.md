# ES2021 Modernization

Use `"target": "ES2021"` and `"lib": ["ES2021", ...]` or newer. ES2021 is useful for logical assignment, `Promise.any`, `AggregateError`, numeric separators, and string replacement.

## Logical Assignment Operators

Use logical assignment when the left side should only be assigned under the matching logical condition.

Use this:

```ts
options.timeout ??= 5000;
cache[key] ||= createValue();
feature.enabled &&= userHasAccess(user);
```

Not that:

```ts
options.timeout = options.timeout ?? 5000;
cache[key] = cache[key] || createValue();
feature.enabled = feature.enabled && userHasAccess(user);
```

Replaces:

- repeated left-hand-side logical assignment patterns

Use with care:

- `||=` treats all falsy values as missing. Use `??=` when `0`, `false`, or `""` are valid.
- Do not use these operators if the repeated explicit assignment is clearer for the team.

## Promise.any And AggregateError

Use `Promise.any()` when the first successful result should win.

Use this:

```ts
const response = await Promise.any([
  fetch(primaryUrl),
  fetch(fallbackUrl),
]);
```

Not that:

```ts
const response = await Promise.race([
  fetch(primaryUrl),
  fetch(fallbackUrl),
]);
```

Replaces:

- `Promise.race()` misuse where early rejection should not fail the whole operation
- custom "first fulfilled" helpers

Use with care:

- `Promise.any()` rejects with `AggregateError` only after every input rejects.
- Use `Promise.race()` when the first settlement, success or failure, should win.

## String.replaceAll

Use `replaceAll()` for literal all-occurrence string replacement.

Use this:

```ts
const slug = title.trim().toLowerCase().replaceAll(" ", "-");
```

Not that:

```ts
const slug = title.trim().toLowerCase().replace(/ /g, "-");
```

Replaces:

- global regexes used only for literal replacement
- split/join replacement

Use with care:

- If the first argument is a regex, it must be global.
- Use regex replacement when matching a pattern, not a literal string.

## Numeric Separators

Use numeric separators to improve readability of large numeric literals.

Use this:

```ts
const timeoutMs = 30_000;
const maxBytes = 10_485_760;
```

Not that:

```ts
const timeoutMs = 30000;
const maxBytes = 10485760;
```

Replaces:

- hard-to-scan large numeric literals
- explanatory comments that only separate digit groups

Use with care:

- Do not churn tiny numbers or values where grouping is not meaningful.
- Match domain grouping: bytes may group by powers of two comments; money-like integer cents may group by thousands.

## WeakRef And FinalizationRegistry

Use `WeakRef` and `FinalizationRegistry` only for advanced caches and resource cleanup where best-effort semantics are acceptable.

Use this:

```ts
const ref = new WeakRef(expensiveObject);
const cached = ref.deref();
```

Not that:

```ts
const cached = globalCache.get(id);
```

Replaces:

- strong-reference caches that are allowed to forget values under memory pressure

Use with care:

- Do not use finalizers for critical cleanup. Timing is not deterministic.
- Prefer explicit lifecycle management for files, sockets, locks, subscriptions, and user-visible resources.
