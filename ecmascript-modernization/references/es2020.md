# ES2020 Modernization

Use `"target": "ES2020"` and `"lib": ["ES2020", ...]` or newer. ES2020 is a major readability upgrade: optional chaining, nullish coalescing, dynamic import, `Promise.allSettled`, `globalThis`, `BigInt`, and `String.matchAll`.

## Optional Chaining

Use optional chaining for safe property, element, and method access.

Use this:

```ts
const city = user.profile?.address?.city;
const firstItem = response.items?.[0];
logger.debug?.("Loaded user", user.id);
```

Not that:

```ts
const city =
  user.profile && user.profile.address && user.profile.address.city;
```

Replaces:

- long `&&` guard chains
- helper functions that only safely read nested properties

Use with care:

- Do not use optional chaining when absence is a bug that should fail loudly.
- Optional chaining only guards the value immediately before `?.`.

## Nullish Coalescing

Use `??` when only `null` or `undefined` should trigger a default.

Use this:

```ts
const limit = options.limit ?? 50;
const title = input.title ?? "Untitled";
```

Not that:

```ts
const limit = options.limit || 50;
const title = input.title || "Untitled";
```

Replaces:

- `||` defaults that accidentally replace `0`, `false`, or `""`

Use with care:

- Keep `||` when all falsy values should fall back.

## Promise.allSettled

Use `Promise.allSettled()` when every task should finish even if some fail.

Use this:

```ts
const results = await Promise.allSettled(jobs.map((job) => job.run()));
const failures = results.filter((result) => result.status === "rejected");
```

Not that:

```ts
const results = await Promise.all(
  jobs.map((job) =>
    job.run()
      .then((value) => ({ status: "fulfilled" as const, value }))
      .catch((reason) => ({ status: "rejected" as const, reason })),
  ),
);
```

Replaces:

- hand-rolled fulfilled/rejected result wrappers
- `Promise.all()` when fail-fast behavior is wrong

Use with care:

- Use `Promise.all()` when one failure should abort the aggregate operation.

## Dynamic import

Use `import()` to load modules lazily or conditionally.

Use this:

```ts
const { renderChart } = await import("./charting.js");
```

Not that:

```ts
const charting = require("./charting");
```

Replaces:

- CommonJS `require()` in ESM code
- eager imports for rarely used heavy modules

Use with care:

- Keep static imports for core dependencies that should be bundled, analyzed, and loaded upfront.
- Check bundler chunking behavior before relying on lazy loading.

## globalThis

Use `globalThis` for cross-environment global access.

Use this:

```ts
globalThis.setTimeout(() => refresh(), 1000);
```

Not that:

```ts
const root =
  typeof window !== "undefined" ? window :
  typeof global !== "undefined" ? global :
  self;
```

Replaces:

- environment-sniffing global-object helpers

Use with care:

- Avoid storing application state on globals unless the architecture already requires it.

## BigInt

Use `BigInt` for integers beyond `Number.MAX_SAFE_INTEGER`.

Use this:

```ts
const nextId = 9007199254740993n;
```

Not that:

```ts
const nextId = 9007199254740993;
```

Replaces:

- unsafe large integer `number` values
- string-only arithmetic helpers for integer math when native `BigInt` fits the domain

Use with care:

- Do not mix `number` and `bigint` arithmetic.
- JSON does not serialize `bigint` by default.
- Keep decimal libraries for money, fractions, and arbitrary precision decimals.

## String.matchAll

Use `matchAll()` to iterate all regex matches with capture groups.

Use this:

```ts
const links = [...html.matchAll(/href="(?<url>[^"]+)"/g)]
  .map((match) => match.groups?.url);
```

Not that:

```ts
const links: string[] = [];
const regex = /href="([^"]+)"/g;
let match: RegExpExecArray | null;

while ((match = regex.exec(html))) {
  links.push(match[1]);
}
```

Replaces:

- manual `RegExp.prototype.exec()` loops for global regex matches

Use with care:

- The regex must be global.
- Avoid regex parsing for complex HTML or languages.
