# ES2019 Modernization

Use `"target": "ES2019"` and `"lib": ["ES2019", ...]` or newer. ES2019 is a strong baseline for array flattening, object construction from entries, optional catch binding, and string trimming.

## Array.prototype.flat

Use `flat()` to flatten nested arrays by a known depth.

Use this:

```ts
const allTags = posts.map((post) => post.tags).flat();
```

Not that:

```ts
const allTags = ([] as string[]).concat(...posts.map((post) => post.tags));
```

Replaces:

- `[].concat(...arrays)` flattening
- local `flatten()` helpers for shallow arrays

Use with care:

- Default depth is `1`.
- Keep explicit recursive flattening when depth or non-array handling is domain-specific.

## Array.prototype.flatMap

Use `flatMap()` when each item maps to zero, one, or many output items.

Use this:

```ts
const visibleActions = users.flatMap((user) =>
  user.active ? user.actions : [],
);
```

Not that:

```ts
const visibleActions = users
  .map((user) => (user.active ? user.actions : []))
  .flat();
```

Replaces:

- `.map(...).flat()`
- reduce-plus-push accumulation for simple one-to-many transforms

Use with care:

- `flatMap()` only flattens one level.
- Keep `map()` when every input should produce exactly one output.

## Object.fromEntries

Use `Object.fromEntries()` to turn entries into an object.

Use this:

```ts
const enabledFlags = Object.fromEntries(
  Object.entries(flags).filter(([, enabled]) => enabled),
);
```

Not that:

```ts
const enabledFlags: Record<string, boolean> = {};

for (const [name, enabled] of Object.entries(flags)) {
  if (enabled) {
    enabledFlags[name] = enabled;
  }
}
```

Replaces:

- entry-loop object reconstruction
- `reduce()` object builders from key-value pairs

Use with care:

- Later duplicate keys overwrite earlier ones.
- Use `new Map(entries)` when key identity is not string/symbol property identity.

## String trimStart And trimEnd

Use directional trim methods when only one side should be trimmed.

Use this:

```ts
const withoutPrompt = line.trimStart();
const withoutNewline = line.trimEnd();
```

Not that:

```ts
const withoutPrompt = line.replace(/^\s+/, "");
const withoutNewline = line.replace(/\s+$/, "");
```

Replaces:

- simple leading/trailing whitespace regexes
- `trimLeft()` and `trimRight()` in new code

Use with care:

- Keep regexes when trimming only a custom character set.

## Optional Catch Binding

Omit the catch binding when the error is intentionally unused.

Use this:

```ts
try {
  JSON.parse(input);
  return true;
} catch {
  return false;
}
```

Not that:

```ts
try {
  JSON.parse(input);
  return true;
} catch (_error) {
  return false;
}
```

Replaces:

- unused `_error` catch bindings

Use with care:

- Keep the binding when logging, classifying, wrapping, or rethrowing the error.
